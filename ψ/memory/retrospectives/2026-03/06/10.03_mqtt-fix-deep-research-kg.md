## Honest Feedback

1. **MQTT/extension infrastructure ไม่ reliable**: ทุกครั้งที่ใช้ /deep-research ต้องมาแก้ปัญหา infra ก่อน วันนี้ 2 issues — mosquitto ไม่รัน + extension URL ผิด ต้องมี health check ก่อนรัน deep-research เช่น ทดสอบ MQTT connection ก่อน แล้ว fail fast พร้อมบอกวิธีแก้

2. **chrome.scripting.executeScript ไม่ทำงานบน Antigravity**: Extension รับ command ได้ (focus_tab ตอบ success) แต่ scripting commands ทั้งหมด timeout ไม่มี error message กลับมาเลย ทำให้ debug ยาก ควรมี timeout + error response ฝั่ง extension

3. **Deep Research ไม่มี end-to-end flow**: สั่ง research ได้ แต่ดึงผลกลับมาไม่ได้ผ่าน extension ต้อง fallback ไป AppleScript ซึ่งต้องเปิด "Allow JavaScript from Apple Events" ด้วย ควรมี script สำเร็จรูปที่ handle ทั้ง flow: start → wait → retrieve

## Lessons Learned

- Mosquitto ต้องมี config file จริง ไม่ใช่แค่ .example — brew services จะ fail silently
- Extension MQTT_URL hardcode = ต้องแก้ทุกครั้งที่ environment เปลี่ยน ควรเป็น configurable
- AppleScript + Chrome JavaScript execution = backup path เมื่อ extension scripting ไม่ทำงาน
- brew services restart จัดการ auto-start ได้ดีกว่า manual mosquitto -d
