## AI Diary

This session had a satisfying arc — from audit to action. The previous session planted the seed when we found ว78 was missing its คู่มือ attachment, and today we scaled that insight across the entire corpus. The chars/page ratio heuristic turned out to be remarkably effective at finding incomplete files. Every single file flagged as suspicious genuinely had missing content.

Writing batch_reocr.py was the most productive moment. The key insight was using a generic OCR prompt instead of the structured ข้อหารือ prompt from ocr.py. The original pipeline's extract prompt is optimized for ruling documents (ข้อเท็จจริง/ข้อหารือ/ข้อวินิจฉัย) which causes Gemini to skip everything that doesn't fit that mold — manuals, templates, wage tables, operational guidelines. These attachments (สิ่งที่ส่งมาด้วย) are often the most substantively useful parts of the document.

I felt some frustration with the gdown dependency miss and the ว456 hang. The gdown issue was my fault — I assumed it was installed without checking. The hang was a Gemini File API issue with large scanned PDFs. Both were recoverable, but they added unnecessary delay. The ค่าแรงงาน chunk 2 returning 0 chars three times is concerning — those 20 pages of wage tables are genuinely lost. Gemini simply refuses to OCR dense numerical tables, which is a known limitation.

The 19x-25x improvement on files like ว1203 and ค่าแรงงาน is wild. These documents went from essentially invisible (3K chars for 77 pages!) to fully searchable. Questions about จ้างที่ปรึกษา, QR code procurement boards, e-bidding payments — all of these can now be answered.

## Honest Feedback

**1. Output buffering waste**: Python's default stdout buffering caused ~15 minutes of confusion where the batch script appeared to produce no output. I should have included `PYTHONUNBUFFERED=1` from the start, or added `flush=True` to print statements. This is a recurring footgun when running Python scripts in background.

**2. Dependency assumption**: I wrote the script using `gdown` without checking if it was installed. The project already had `stream_pdf()` in drive.py which was the right tool. Should have checked existing utilities first before reaching for external dependencies.

**3. Gemini reliability on large scans**: ว456 (4.5MB, 13 pages) caused a complete hang on first attempt but worked fine on second. ค่าแรงงาน chunk 2 returned 0 chars three times (dense wage tables). There's no good workaround for these failure modes — the script has retry logic but Gemini just can't handle certain content types. A future improvement could be to flag these failures for manual review rather than silently accepting 0 chars.

## Lessons Learned

- **Generic OCR prompt beats structured prompt for heterogeneous documents**: The ข้อหารือ-structured extract prompt causes Gemini to skip non-matching content (manuals, templates, tables). A simple "copy everything verbatim" prompt captures all content.
- **chars/page ratio is a reliable OCR completeness heuristic**: ratio < 50 with pages > 10 reliably identifies incomplete OCR. All 9 flagged files genuinely had missing content.
- **Always check existing project utilities before adding dependencies**: `stream_pdf()` already existed in drive.py — no need for gdown.
