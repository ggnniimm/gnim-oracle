## Lessons Learned

1. **ตรวจ section headers หลัง OCR** — ถ้าชื่อไฟล์มี "ข้อหารือ" แต่ไม่เจอ `## สรุปข้อวินิจฉัย` ในเนื้อหา → re-OCR ทันที ไม่ต้องรอ human review
2. **Drive folder discovery** — scan root folders ทุกครั้งก่อน OCR เพื่อ detect folders ใหม่ที่ไม่อยู่ใน known list
3. **Re-OCR (force=True) ดีกว่าแก้ manual** — Gemini รอบ 2 มักทำได้ดีกว่าเพราะ context ไม่ถูก confuse จาก first-pass cache
