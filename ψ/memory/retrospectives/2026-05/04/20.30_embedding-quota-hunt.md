## Lessons Learned

1. Google Cloud มีสอง billing systems แยกจากกัน: Vertex AI (GCP credits) ≠ AI Studio (prepayment) — $300 GCP trial credits ใช้กับ AI Studio API ไม่ได้ explicitly excluded ใน ToS
2. Vertex AI embedding quota (~7 texts/min) เป็น platform policy ไม่ใช่ per-project — ทุก project ใหม่ได้ quota เดิม ต้องขอเพิ่มเท่านั้น
3. `unset VARIABLE` ใน shell ไม่พอถ้ามี `.env` file — `load_dotenv` จะ set ค่าจากไฟล์มาทับ ต้องใช้ `export VARIABLE=` (empty string) แทน
4. Embedding model = foundation ของ RAG knowledge space — เปลี่ยน model = ต้อง re-tune ทุกอย่างใหม่ (cross-refs, rescue phrases, TCs)
