## Lessons Learned

**Probe Vertex Studio before assuming key status**. Memory said "this key is suspended" or "this key is the working one" — both were stale. A 5-second `curl https://generativelanguage.googleapis.com/v1beta/models?key=K` returns ground truth (HTTP 200 = active, INVALID/REVOKED, or PERMISSION_DENIED). Cheap to verify; expensive to assume.

**`docker compose restart` ≠ env reload**. To pick up `.env` changes you need `docker compose up -d` to recreate the container. Verify with `docker exec ... env | grep VAR`. Restart preserves the original env vars from container creation time. (MEMORY.md candidate.)

**Prod source can drift from local**. We saw two distinct drifts today: prod's `config.py` was an older hardcoded version; prod's `app/` had the same content as local but is COPY'd at build time, not mounted. The mount list in `docker-compose.yml` is the only authoritative source-of-truth for what's hot vs baked. Never assume parity — grep the file on prod first.

**Vertex global endpoint is a different quota tier**. Per-region preview = ~7-10 calls/min. Global GA = ~435 calls/min. When Google promotes a model to GA, the global endpoint usually has dramatically higher quota than regional even before requesting an increase.

**`gemini-embedding-2-preview` ≡ `gemini-embedding-2` GA**. They are aliases; cosine of vectors is 1.000000 across all task_types. Migration between them is a config-only change, no re-index. *(Generalize to: when a preview model graduates to GA, **probe cosine** before assuming you need to re-index.)*
