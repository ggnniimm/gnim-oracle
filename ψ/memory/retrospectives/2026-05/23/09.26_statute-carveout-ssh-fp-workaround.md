## Lessons Learned

See dedicated learning files (already saved in this session):
- **OCR ๒๔→๒๕ pattern**: gemini-2.5-pro confuses these digits in doc-number position. Filename + Ming's intent > OCR output > Google Drive native OCR (worst).
- **`is_specific_query` design hole**: dropping vector lane works for 4-digit doc-IDs but breaks for statutory provisions where the section number is too common. Fix = carve-out filter on known statute file_ids.
- **`appleboy/ssh-action` fingerprint opacity**: no "got X expected Y" detail. If host key rotates, don't burn time on format-tweaking — drop `fingerprint:` or switch action.

Meta-lesson: **layered investigations need explicit "stop and re-orient" checkpoints**. When 3 layers deep into a debug, pause and ask: "what's the smallest thing that would unblock the user right now?" Often the answer is a workaround + a saved learning, not the full perfect fix.
