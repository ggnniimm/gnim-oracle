## Lessons Learned

**Pattern: Thai procurement law has a temporal split in contract terms**

Before signing:
- Procurement docs can be changed freely (if state benefits)
- Contractors can request term changes (e.g., waive advance payment)
- No contract amendment needed — just change the bid docs

After signing:
- Contracts are locked (มาตรา 97, วรรค 1: "แก้ไขไม่ได้")
- Changes require exemption (state benefit OR no state loss, case-by-case)
- Requires ministerial sign-off if complex
- Must be done before final delivery acceptance

**Ming's question reveals this split**: The answer changes based on timing.
