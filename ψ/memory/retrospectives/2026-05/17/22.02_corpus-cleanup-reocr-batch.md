## Lessons Learned

1. **OCR classifier ใช้ "ว" rule → อาจ misclassify ข้อหารือที่มีลายมือเลือน** บังคับ doc_type ด้วยการ call `extract()` โดยตรงแทน `pdf_to_markdown()`
2. **PDF ใหญ่ >1MB → ใช้ per_page=True** ป้องกัน 504 timeout
3. **Filename ของ Thai gov documents บางครั้งเป็น source of truth ที่ดีกว่า OCR** เช่น 10515.md → doc_number = ๑๐๕๑๕
