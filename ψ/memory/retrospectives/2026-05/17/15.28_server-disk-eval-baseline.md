## Honest Feedback

**1. Drift warning ที่ผิดพลาดตอนแรก**
ตอนเปรียบเทียบ 2 วิธี index บอกว่า "local = 29,746 dedup rows, prod = 31,368 chunks" ซึ่งตัวเลขผิดทั้งคู่ — prod จริงๆ คือ 31,927 (ไม่ใช่ 31,368 ซึ่งเป็นตัวเลขก่อน Phase 1 เมื่อเช้า) และ local Qdrant ก็ 31,927 เช่นกัน การเอาตัวเลขจาก memory มาใช้โดยไม่ verify ก่อนทำให้ข้อมูลผิด ควร query จริงทุกครั้ง

**2. ว126 force-reindex แล้วยังไม่ช่วย**
ใช้เวลา index ว126 (~90s รอ quota) แต่ผลคือ TC-045 ยังไม่ retrieve doc นั้นขึ้นมา น่าจะวิเคราะห์ก่อนว่า retrieval จะ pick doc นี้ได้ไหมก่อน force-reindex เสมอ เพราะถ้า query กว้างกว่า doc ก็จะแพ้ rank อยู่ดี

**3. ควรเช็ค ว126 บน prod ก่อนบอกว่าต้อง index**
บอก Ming ว่า "ว126 ไม่อยู่บน prod ต้อง index" แต่จริงๆ มีอยู่แล้วครบ 14 chunks ข้อมูลที่ report ออกไปผิด ควร verify prod ก่อนสรุป
