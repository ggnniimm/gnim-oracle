## Honest Feedback

**Friction 1 — pipe buffering mistake (cost: 41 minutes, demoralizing)**: I didn't apply a memory entry I had literally read in this session. The fix was trivial (`python -u` + direct redirect, no tee/tail). The cost was real: a chunk of API quota burned, user time wasted waiting, and a credibility dent. I need to treat memory entries as constraints I plan around, not warnings I acknowledge. Before any long-running script: explicitly ask "how will I see progress?" and write that into the command.

**Friction 2 — over-instrumentation early, under-instrumentation later**: I scheduled wakeups every 4-10 minutes during the buffering blackout, polling a process I had no signal on. I should have checked once after 5 min, seen 0 bytes, killed, restarted with -u. Instead I waited 41 min for "self-flush." This wasn't patience; it was avoidance of admitting the setup was wrong. The right move is fast detection + fast pivot, not extended hope.

**Friction 3 — claiming "no quality regression" on N=5**: Stage 1 returned all rank 1 → rank 1, and I phrased it as "no signal that 001 is worse." That's technically true but easy to misread as "001 is fine to migrate to." Advisor warned me; I noted it; I still risked the framing. If I'd presented it as "5 datapoints, all positive, but well within where false-pass is plausible," Ming would have a clearer picture for the deploy-or-not decision.

## Lessons Learned

1. **Vertex AI embedding quota is per-(project, region, model)** — not platform-wide. The memory entry "ALL Vertex AI projects share same low default quota" was true for *single-pool* usage but missed that bypassing via multi-region works. Round-robin across 5 regions × 1 project = ~5x throughput; add SA-key projects for more. **Vectors are byte-identical across regions/projects** (cosine=1.0), safe to mix in one Qdrant collection.

2. **Pipe-buffering rule needs to be a planning step, not a warning.** Whenever I run a long Python job I must (a) use `python -u` and (b) redirect directly to a file with no `| tail` chain. This rule already exists in memory but didn't fire when needed.

3. **Vertex AI model availability lags docs.** `gemini-embedding-2` GA is in docs since 2026-04-22 but returns 404 on ms-default project. Don't trust docs as ground truth for "is this callable from my project right now" — always probe with a real call.
