## Lessons Learned

**1. MMR see-saw is a diagnostic, not a problem to solve.**
When two docs are so semantically similar that boosting one pushes the other out, the retrieval architecture is working correctly — it's enforcing diversity. Fighting it by adding competing BM25 anchors creates fragility. The right call: accept the ⚠, or use cross-ref injection intentionally.

**2. Query direction determines retrieval ceiling for counterpoint docs.**
ref_sac_o_72_2564 says "ไม่ต้องรับผิด" but TC-066's query semantically attracts "ต้องรับผิด" content. No amount of keyword matching can overcome this — the embedding space already encodes the answer direction. A counterpoint doc can only be reliably retrieved when the query specifically asks for the counterpoint (e.g., "กรณีที่ผู้รับจ้างไม่ต้องรับผิด").

**3. Cross-ref inject is not a hack — it's the correct tool for counterpoint cases.**
When two docs describe the same scenario with opposite conclusions, the only way to guarantee both appear in one answer is to inject the counterpoint content into the doc that wins retrieval. This isn't gaming the system; it's encoding the legal nuance that the query naturally won't surface.
