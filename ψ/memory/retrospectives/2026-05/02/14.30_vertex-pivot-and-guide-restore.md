## Decisions worth remembering

- **Don't change embedding models** to chase quota. `gemini-embedding-001` has 2x quota of `2-preview` but requires re-indexing 28K chunks — net loss.
- **Don't deploy from local-PASS alone**. Local Qdrant has content drift, not just chunk-count drift. Prod retest is mandatory for any eval-affecting change.
- **Synthetic docs need protection**. The guide doc was created in this repo only and got purged in resync. Future synthetic/cross-ref docs should either go in the sibling source-of-truth repo too, OR be marked in some way the resync respects. (Not solved — note for future.)
- **TC-082/083/084 are arithmetic-application TCs** — guide doc fixes mode-1 (retrieval/quoting); mode-2 (LLM applies the rule consistently) is inherent variance. Currently ~70% pass rate. Either accept as flaky or build a deterministic date-arithmetic tool — out of scope for this session.
