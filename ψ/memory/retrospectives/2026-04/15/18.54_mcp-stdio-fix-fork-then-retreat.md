## Lessons Learned

1. **ลำดับการเสนอ options มี bias**: การเสนอ heavy option ก่อนทำให้ user รู้สึกว่าต้องถอยออกมา. เสนอ light option ก่อนทำให้ user รู้สึกว่าต้องตัดสินใจเดินหน้า. Default ที่เหมาะสำหรับงานที่แตะ infrastructure คนอื่น = light option ก่อน.
2. **"ทำแล้ว" ≠ "ถอยไม่ได้"**: `git push fork --delete` ราคาถูก. อย่าตีกรอบตัวเองว่า irreversible เมื่อมันยัง reversible.
3. **MCP stdio invariant**: (จาก session ก่อน, ยังใช้อยู่) — ห้ามเขียน stdout ใน MCP server ยกเว้น JSON-RPC frames. ทุก `console.log` = landmine.
4. **Uncommitted WIP ที่ไม่ใช่ของเรา = ต้องถาม**: เจอ modified files ที่ไม่เกี่ยวกับงานปัจจุบัน → ควรถามทันทีว่าของใคร/ทำค้างทำไม, ก่อนจะ stash หรือเดินหน้า.
