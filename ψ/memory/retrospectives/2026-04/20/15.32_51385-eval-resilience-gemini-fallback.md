## Lessons Learned

- **`python3 -u` เป็น must-have สำหรับ eval background runs** — block-buffered stdout ทำให้ดูเหมือน hung
- **Diagnose before fix**: `lsof -p $PID` + check file descriptors ก่อนเดาว่า network issue
- **`ThreadPoolExecutor.shutdown(wait=False)`** — วิธีที่ถูกต้องในการ timeout โดยไม่ block main loop (with-context manager รอจะเสร็จ)
- **LLM variance calibration**: TC rerun 3x ที่ได้ 1-2 fails / 3 runs = borderline, ไม่ใช่ regression จริง
- **Fallback chain matters**: Gemini 2.5-flash + 2.5-flash-lite + flash-latest routes ไป backend pool ต่างกัน — อย่าใส่ 2.0-flash (404 deprecated)
