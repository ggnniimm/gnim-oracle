## Lessons Learned

1. **Always sample one payload before Qdrant field-name queries** — field names in production Qdrant may differ from local code. One `client.scroll(limit=1, with_payload=True)` and print `.payload.keys()` takes 5 seconds and prevents wrong-field failures.
2. **Clean up mental models when code changes** — when a flag/feature is removed from code, also remove it from memory and suggested commands. "Deprecated, ignored" in code ≠ OK to keep suggesting.
