## Honest Feedback

**Friction 1 — Streamlit CSS positioning ล้มเหลวโดยไม่มี warning**
ทดลอง CSS inject หลายรอบในหลาย session แต่ Streamlit ไม่ให้ทำ interactive elements ใน toolbar area และไม่มี error — แค่ render ผิดที่ทุกครั้ง ถ้า Streamlit มี official way ทำ custom header would have been easier น่าจะ communicate ให้ Ming รู้ตั้งแต่แรกว่า top-right placement เป็นไปไม่ได้ แทนที่จะลองหลายรอบแล้วค่อยยอมรับ

**Friction 2 — Docker cached build ที่ไม่ได้ sync ไฟล์ก่อน**
Pattern นี้เกิดซ้ำหลายครั้ง: แก้ local → build remote → cached → งงว่าทำไมไม่เปลี่ยน ต้อง scp ก่อนทุกครั้ง ควร create workflow ที่ชัดเจนกว่านี้ หรืออย่างน้อย always scp before build เป็น habit

**Friction 3 — Context reconstruction จาก summary ไม่ perfect**
Session นี้ได้ context จาก auto-summary ของ session ก่อน ซึ่งดีมาก แต่ยังต้อง read current file state ก่อนทำงานเสมอ เพราะ summary อาจ stale ได้ ครั้งนี้อ่าน streamlit_app.py ก่อน edit ซึ่งถูกต้อง แต่ต้องจำไว้ว่านี่เป็น required step ไม่ใช่ optional
