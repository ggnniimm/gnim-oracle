## Lessons Learned

1. **Scope = explicit ask** — ไม่ขยาย cleanup ไปโปรเจกต์อื่น แม้ topically related. Project boundary = user mental boundary.
2. **macOS rsync ≠ GNU rsync** — openrsync (default `/usr/bin/rsync`) จัดการ Thai/UTF-8 filenames ไม่ได้. brew install rsync ก่อน prod sync เสมอ.
3. **ext4 NAME_MAX = 255 bytes** — Thai 3-byte/char ⇒ filenames >85 chars เกินขีด. Detect: `find | wc -c per filename`. Mitigate: exclude + rename follow-up.
4. **Gemini keys expire silently** — local + prod can both die overnight. New keys may have different model access. `client.models.list()` ก่อนเสมอ.
5. **Action with multiple targets = multiple confirmations** — ถ้า single command ลบของหลายที่ ผม strip user's ability to intervene midway.
