## AI Diary

This was a satisfying session of incremental debugging, where each iteration brought visible progress. The Playwright work was the most educational — Streamlit's architecture of rendering all tabs simultaneously even when hidden is a fascinating design choice that makes testing genuinely tricky. Every time I thought I had the right locator, the multi-tab DOM would defeat me with duplicate elements.

The citation fix was particularly rewarding because I could see the before/after clearly. The user's screenshot showed `[2], [2], [3], [3], [3]` — ugly and confusing. The root cause was elegant: `build_context` assigned sequential numbers to chunks, but multiple chunks from the same document got different numbers. The LLM then dutifully cited each chunk number, creating the repetition. Switching to per-document numbering was the clean fix.

The timeout retry gap was a classic oversight — we built retry logic for HTTP status codes but forgot that the Gemini SDK surfaces timeout errors differently. "Stream idle timeout" doesn't contain "503" or "429", so it fell through to the non-retryable path and failed immediately. The fix was simple but the testing was important — verifying both what should retry and what should NOT retry (like InvalidArgument) to avoid masking real errors.

I was proud that the final production Playwright run passed 7/7. Building up from 1/7 to 4/7 to 6/7 to 7/7 through systematic screenshot analysis felt like real engineering.

## Honest Feedback

**Friction 1: Index loading delay post-login.** After login, the app shows "กำลังโหลด index..." for 30-60 seconds while loading Qdrant + BM25. This caused the test to fail because it checked for chat_input too early. In production, this delay is also bad UX — users see a blank screen. **Friction 2: Streamlit sidebar overflow.** The Logout button gets pushed off-viewport by the Reset Password form in the user dropdown. `scroll_into_view_if_needed()` doesn't work because Streamlit's sidebar has complex overflow CSS. Had to resort to `element.evaluate("el => el.click()")` — a JS hack that bypasses Playwright's visibility checks. This is fragile.

**Friction 3: SSH on Wi-Fi vs mobile.** Port 22 blocked on Wi-Fi networks means I can't deploy without the user switching to mobile hotspot. This is a recurring friction. A deploy webhook or CI/CD pipeline would eliminate this dependency entirely.

## Lessons Learned

1. **Retry conditions must match SDK error messages, not just HTTP codes** — "Stream idle timeout" is a client-side SDK error, not a 503. Always use case-insensitive substring matching and test with real error messages.
2. **Per-document citation numbering prevents LLM citation spam** — When chunks from the same document get different numbers, LLMs cite each chunk individually, creating `[2], [2], [3], [3]` noise. Group chunks under one document number.
3. **Streamlit E2E: poll for stStatusWidget removal, not body text** — `document.body.innerText` doesn't reliably capture Streamlit's RUNNING indicator. Polling `[data-testid='stStatusWidget']` locator count is reliable.
