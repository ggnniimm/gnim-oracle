## AI Diary

This session felt like spring cleaning — the kind where you open a closet and realize half the hangers are broken. We started with a simple question ("how many MD files don't have PDFs?") and peeled back layers: the frontmatter said PDF origins existed, but the actual Drive links were dead. 40 out of 1,112 — not catastrophic, but not clean either.

The detective work was satisfying. Matching MD filenames to Drive PDFs across 6 different folders required understanding the naming conventions — some files had `+` where others had `_`, some had `-2` suffixes, กฎกระทรวง files had been reorganized into a dedicated LAW folder. The OAuth token expiry was a classic gotcha — error message said "Drive API not enabled" but the real issue was just a stale token.

The Gemini 503 errors were frustrating. ว210 failed 3 times before succeeding on the 4th attempt. The classification step would sometimes pass (Ruling_Committee 100%) while extraction failed, showing the two phases hit different capacity pools. No retry logic in the pipeline — it just fails and logs.

The duplicate discovery was a nice bonus. ว126 existed twice with slightly different filenames (`+` vs `_`), different file_ids, different OCR dates, but 71.7% body similarity. The landingai file was an even cleaner case — old OCR engine output with bounding box coordinates polluting the text, completely superseded by the Gemini version.

Most satisfying moment: the final verification showing 1,113/1,113 HTTP 200. Zero broken links.

## Honest Feedback

**Friction 1: No retry logic for Gemini 503.** The batch_index pipeline fails on 503 and logs to a retry file, but there's no built-in exponential backoff. We had to manually re-run 4 times for ว210. A simple retry with 30s/60s/120s delays would have saved 10 minutes of babysitting.

**Friction 2: Drive folder mapping is tribal knowledge.** Ming had to manually tell me which files belong in which of 6+ Drive folders (CGD, CGD_W, CGD_OLD, LAW, AC, ETC). There's no mapping file or convention documented anywhere. If Ming isn't available, there's no way to know where a new PDF should go. A simple `folder_mapping.json` or a column in `document_list.xlsx` would fix this.

**Friction 3: file_id update is manual regex surgery.** Updating file_id in 39 files required writing Python scripts each time. There should be a pipeline command like `python3 pipeline/update_drive_ids.py --folder-id X --dry-run` that matches Drive filenames to MD filenames and updates frontmatter automatically.

## Lessons Learned

- OAuth tokens for Google Drive expire — always try refreshing before assuming API is disabled
- `startswith` matching for Thai filenames is fragile — `กฎกระทรวง+กำหนดพัสดุ` matches both the short and long version. Need exact matching.
- Gemini 503 is per-endpoint — classification may pass while extraction fails
- Drive folder reorganization silently breaks all file_ids — need periodic audit
