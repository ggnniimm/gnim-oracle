## Lessons Learned

**กฎวันหยุด (ค่าปรับ)**: ถ้าวันครบกำหนดตรงวันหยุด → เลื่อนเป็นวันทำการถัดไปเสมอ → เริ่มผิดนัดวันถัดจากนั้น ไม่มีเงื่อนไข อ้างอิง: กวจ 51349 + ป.พ.พ. ม.๑๙๓/๘

**Knowledge doc ต้องมี warning ชัดเจน**: formula เปล่าไม่พอ ต้องมี "Gross endpoint = วันผ่านตรวจ ไม่ใช่วันส่ง" และ "deduction แต่ละครั้งอิสระจากกัน" เป็น bullet ชัดๆ ไม่งั้น LLM อ่านสูตรแล้วยังคิดผิดได้

**python3 -u สำหรับ long-running eval**: ควรรันด้วย `python3 -u` เสมอเพื่อ unbuffered output → ผู้ใช้เห็น progress real-time
