## Lessons Learned

1. **ตรวจ sim floor ก่อน anchor engineering** ถ้า document มี chunk ที่มี sim score สูง (>0.80) อยู่แล้ว anchor แยก section จะไม่ขึ้น ต้องตรวจ `sim scores ของทุก chunk ใน document` ก่อนตัดสินใจว่า anchor approach จะได้ผลหรือไม่

2. **เพิ่ม content ใน chunk ที่มี score สูงอยู่แล้ว = dilute** การ append paragraph ที่ไม่ตรง query เข้าไปใน chunk จะลด sim score เสมอ ไม่ใช่เพิ่ม ถ้าต้องการให้ chunk มี phrase ใหม่ ต้อง restructure chunk ทั้งหมดให้ phrase ใหม่กลมกลืนกับ semantic ของ query

3. **must_contain ต้องมาจาก query semantics ไม่ใช่ document content** "แผน" เป็น phrase จาก 20140 แต่ไม่ใช่ concept ที่ query "หน้าที่ทั่วไป" จะดึงออกมาอย่างสม่ำเสมอ ถ้าต้องการ test เรื่อง "แผน" ต้องสร้าง TC ที่ query ถามเรื่องนั้นโดยตรง
