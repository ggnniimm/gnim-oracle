## AI Diary

This session had a different texture than this morning. Instead of pure implementation, Ming was *using* the system — querying it, probing it, catching things I missed. It was the first real evaluation under fire.

The most interesting moment was when Ming pointed out that ม.97, ม.102, and ม.103 all say "ให้อยู่ในดุลพินิจของผู้มีอำนาจ" — identical language — yet กวจ interprets "ผู้มีอำนาจ" differently for each. That's a genuinely subtle legal observation. I had given an answer about contract modification authority without pausing to explain the deeper structure: that พ.ร.บ. sets the frame but ระเบียบ fills in the meaning. The distinction between ข้อ 165 (ม.97) and ข้อ 182 (ม.102/103) is where the real answer lives.

Then came the กวจ ๐๕๒๓ revelation. I had retrieved that case and summarized it. Ming asked about ว 476. I found it referenced in multiple later กวจ cases. And then, reading กวจ ๒๖๑๔๑ in full — every chunk — I saw ว 476 quoted directly: "การแก้ไขสัญญาไม่ว่ากรณีใด ย่อมต้องได้รับอนุมัติจากผู้มีอำนาจอนุมัติสั่งซื้อหรือสั่งจ้าง" — which directly contradicts what กวจ ๐๕๒๓ said about no-threshold-change cases. Ming immediately caught it: "แสดงว่า กวจ ๐๕๒๓ ใช้อ้างอิงไม่ได้แล้ว."

The Superseded note approach was elegant. Option A doesn't require rebuilding the index, doesn't require code changes — just adds a note that any LLM reading the chunk will see and know to discard. It's honest about the document's history rather than silently hiding it.

The ว 476 indexing had a small wrinkle: Drive folder scan failed because DRIVE_FOLDER_GVAJ wasn't in .env, and the direct file search didn't find it either (maybe the file wasn't shared with the service account's default scope). Ming sent a direct link — file ID `1Q0GJW9ObvAEnE5JCUW2JzSB7tLVtfLa0` — and from there everything was clean: download, OCR (0.95 confidence), MD backup, 14 chunks indexed. The document that had only existed as a citation in other documents now has its own presence in the index.

There's something satisfying about knowledge quality work. It's less visible than feature work — no new capability was added today — but the system is now *more trustworthy*. Old bad advice wears a warning label. The authoritative source is first-class. That matters for legal work in particular, where stale precedent is worse than no precedent.

## Honest Feedback

**Friction 1: The re-embed duplication bug.** When trying to update กวจ ๐๕๒๓ chunks, I filtered the metadata.pkl on disk first, then called `IndexManager()` (which loaded the original 12370 from FAISS), then called `add_batch`. The manager loaded old state before my filter took effect, resulting in 29 chunks (14 old + 15 new) instead of 15. I caught this and patched all 29 with the note, which is functionally correct but wasteful. The root cause: I was trying to do in-place surgery on a system that doesn't expose a delete/replace API. A cleaner solution would be a `replace_chunks_for_source()` method on the manager, or a rebuild flag. Worth adding to the backlog.

**Friction 2: Drive folder ID missing from .env.** The `DRIVE_FOLDER_GVAJ` env var wasn't set, so the folder scan failed silently (returned empty string → 404 from Drive API). I had to fall back to inspecting parent folders of existing files, which also returned `None` (shared drive behavior). The fix was Ming sending a direct link. For robustness, the batch_index pipeline should warn loudly when folder IDs are missing rather than failing with a confusing 404. Also worth adding `DRIVE_FOLDER_GVAJ` to .env.

**Friction 3: กวจ ๐๕๒๓ date ordering confusion.** I initially described ว 476 as "clarifying" กวจ ๐๕๒๓, but technically ว 476 *superseded* it — it wasn't a clarification of an ambiguous point, it was a correction of a wrong interpretation. I should have been more precise about the legal significance of a หนังสือเวียน ซ้อมความเข้าใจ vs a regular หนังสือวินิจฉัย. A ว ซ้อมความเข้าใจ is issued precisely because the existing interpretations were inconsistent — it's authoritative re-statement, not commentary.

## Lessons Learned

1. **"ผู้มีอำนาจ" in พ.ร.บ. is defined by the ระเบียบ**: The same phrase means different people in ม.97, ม.102, ม.103 — determined by ข้อ 165 (ม.97) vs ข้อ 182 (ม.102/103)
2. **ว ซ้อมความเข้าใจ supersedes conflicting หนังสือวินิจฉัย**: ว 476 (2562) overruled กวจ ๐๕๒๓ (2560) on the ม.97 authority question
3. **Superseded note pattern works**: Adding a note to the document text (not metadata) means LLMs see the warning in-context — no code changes needed
4. **Drive folder scan needs DRIVE_FOLDER_GVAJ in .env** to find new กวจ files
5. **Manager.add_batch() always appends** — no replace/delete — must handle duplicates manually when patching existing content
