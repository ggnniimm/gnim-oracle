## Honest Feedback

**3 friction points:**

1. **API key leaked ใน conversation** — ทั้งเซสชันก่อนหน้าและเซสชันนี้มีการพิมพ์ key เป็น plaintext ใน bash command ที่โชว์ใน conversation Claude ควรตั้งค่าโดย default ว่าไม่ show env vars ใน command output หรือ mask ค่า sensitive ออก ระบบที่ดีไม่ควรรอให้ key ถูก block ก่อนถึงจะรู้ว่ามีปัญหา

2. **Query expansion ทำลาย precision สำหรับ specific queries** — expand=True เหมาะสำหรับ broad questions แต่ query เฉพาะเจาะจงอย่าง "ข้อ 11 กฎกระทรวงผู้ประกอบการ" ต้องการ precision ไม่ใช่ recall ควรมีกลไก detect query type และ toggle expansion ตามความเหมาะสม

3. **ทดสอบ Option C ต้อง inject chunks มือ** — end-to-end test ที่แสดง amendment-awareness จาก user query → retrieval → generation ยังทำไม่ได้โดยอัตโนมัติ เพราะ retrieval layer ตัด amendment chunks ทิ้งก่อนถึง LLM ทำให้ demo ไม่สมบูรณ์ในระดับ production

## Lessons Learned

1. ไม่ hardcode API key ใน bash command ใด ๆ — ส่งผ่าน `source .env` หรือ `$ENV_VAR` เสมอ
2. Python 3.10+: `asyncio.get_event_loop()` ไม่สร้าง loop ใหม่ → ใช้ `asyncio.run()` แทน
3. Query expansion เหมาะสำหรับ recall แต่ทำลาย precision — specific legal queries ควร no-expand
