## Honest Feedback

**1. Gemini key danger zone.**
`--cleanup` และ `--resplit` ทำงานกับ ALL sections ทุกครั้ง ถ้า key ผิด = disaster (159 diffs จาก 88) ต้องมี dry-run หรือ section lock mechanism ก่อนจะปลอดภัยจริง

**2. Rate limit ช่วงบ่าย.**
เจอ rate limit ตอน 14:51 ทั้งที่ยังมีงานค้างอยู่ (context compact + ยัง debug ไม่เสร็จ) ทำให้ session ตัดกลางคัน สูญเสีย momentum ที่สะสมมาตลอดเช้า ควรวางแผน commit บ่อยกว่านี้เพื่อลด cost ของการถูกตัด

**3. compare_fresh.py ไม่ได้ใช้จริง.**
สร้าง `compare_fresh.py` ขึ้นมาเพื่อ bypass cache แต่ผลไม่ valid (ไม่มี Gemini key) ทำให้ลดความมั่นใจชั่วคราว เครื่องมือที่ต้องพึ่ง external service ควร fail gracefully กว่านี้

## Lessons Learned

- **OCR cache อยู่ใน repo** (`data/ocr_cache/law_*.json`) — ไม่ใช่ local-only อย่างที่คิด
- **Gemini key**: env var ชื่อ `GEMINI_API_KEY_1_ggnngm` ต้อง pass เป็น `GEMINI_API_KEY` ตอนรัน
- **`--cleanup` danger**: รัน Gemini กับ ALL sections — ถ้า key ผิด = diffs พุ่ง → ต้องตรวจ key ก่อนทุกครั้ง
- **Trailing heading pattern**: sentence-final word บรรทัดก่อน + บรรทัดสั้นไม่มี legal markers = heading ของมาตราถัดไป ตัดทิ้งได้เลย
- **Inline content bug**: label + content บรรทัดเดียว → text ว่าง → 0 paragraphs → paragraphs เก่าใน cache อยู่ผิดที่
