เอกสารกฎหมายไทย (ข้อหารือ/คำวินิจฉัย) มีโครงสร้างซ้ำ:
> ข้อเท็จจริง → ประเด็นข้อหารือ (A หรือ B?) → ข้อวินิจฉัย (คำตอบ) → สรุปข้อวินิจฉัย

ถ้า chunk ที่ rank สูงสุดดึงมาจากส่วน **ข้อเท็จจริง/ประเด็น** เพียงอย่างเดียว LLM จะเห็น "A หรือ B?" โดยไม่มีคำตอบ และมักเลือก A (ตัวเลือกแรก)

**Why:** พบจาก amin's chat session 2026-04-17 — query "ผู้มีอำนาจงดหรือลดค่าปรับคือใคร" ได้ chunk จาก `๑๘.pdf` ที่มีข้อความ "หัวหน้าหน่วยงาน **หรือ** ผู้มีอำนาจอนุมัติสั่งซื้อ?" RAG จึงตอบว่า "ผู้มีอำนาจอนุมัติสั่งซื้อ" แทน "หัวหน้าหน่วยงานของรัฐ"

**How to apply:**
- เมื่อพบว่า RAG ตอบผิด ให้เช็กว่า chunk rank 1 มาจากส่วน "ตั้งคำถาม" หรือส่วน "ตอบคำถาม"
- Fix: เพิ่ม bullet ใน `## สรุปข้อวินิจฉัย` ที่ระบุคำตอบโดยตรง พร้อม negation ("ไม่ใช่ X") เพื่อป้องกัน false positive
- ใส่ทั้ง affirmative ("คือหัวหน้าหน่วยงานของรัฐ") และ negation ("ไม่ใช่ผู้มีอำนาจอนุมัติสั่งซื้อ") ใน bullet เดียวกัน
- Bullet ต้องอยู่ต้น สรุปข้อวินิจฉัย เพื่อไม่ให้ CHUNK_SIZE=400 ตัดทิ้ง
