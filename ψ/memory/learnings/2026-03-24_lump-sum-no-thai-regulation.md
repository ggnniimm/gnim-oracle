# Lump Sum vs Unit Price — No Thai Government Document Defines Selection Criteria

The statement "ราคาเหมารวม ใช้เมื่อแบบรูปรายการสมบูรณ์ ปริมาณงานแน่นอน / ราคาต่อหน่วย ใช้เมื่อแบบไม่สมบูรณ์" has **no single Thai government source**.

**Why:** Thai government docs (พ.ร.บ. จัดซื้อจัดจ้างฯ 2560, ระเบียบ, หลักเกณฑ์ราคากลาง, ว271) define procedures and templates but leave contract type selection to agency discretion. FIDIC Red Book (re-measurement) vs Yellow Book (lump sum) is the origin — practitioners synthesized it into a simpler Thai heuristic.

**How to apply:** In RAG answers, frame as "หลักปฏิบัติทั่วไปในงานก่อสร้าง" not as a regulation. If asked for source, point to FIDIC principles and ว271 as the template that offers both options.

**Verified by searching:**
- ว271 (139 pages) — has both options, no selection criteria
- หลักเกณฑ์การคำนวณราคากลางงานก่อสร้างอาคาร (282 pages) — zero mentions of เหมารวม
- price.moc.go.th methodology (306 pages) — only mentions เหมารวม in labor cost context
- 32+ md_backup files — all USE the concept, none DEFINE criteria
- Multiple web searches — industry sites repeat the criteria, none cite a government source
- FIDIC official guide — Red Book = employer design/re-measurement, Yellow Book = contractor design/lump sum
