## Pattern

เมื่อประเมินว่า document X จะตอบคำถาม Q ได้ถูกต้องไหม ให้ดู **สรุปข้อวินิจฉัย** ก่อน ไม่ใช่แค่ grep หาคำในไฟล์

## ตัวอย่างจริง (2026-05-05)

- **51419** มี line 91: "เป็นอำนาจของหัวหน้าหน่วยงานของรัฐที่จะเป็นผู้พิจารณาบอกเลิกสัญญา" ✓
- แต่ **สรุปข้อวินิจฉัย** (line 96) เขียนแค่ "ผู้มีอำนาจ" — ไม่ระบุว่าใคร
- ผลลัพธ์: RAG ดึง chunk สรุปข้อวินิจฉัยมาก่อน → LLM ตอบกลางๆ ว่า "ผู้มีอำนาจตาม มาตรา 103"
- **Fix**: แก้สรุปข้อวินิจฉัยให้ระบุ "หัวหน้าหน่วยงานของรัฐ ตาม มาตรา ๑๐๓ ประกอบ ข้อ ๖"

## กฎ

1. **ตรวจ สรุปข้อวินิจฉัย ก่อน** เมื่อจะประเมิน doc ว่าตอบถูกไหม
2. **"อยู่ใน corpus" ≠ "จะถูก retrieve"** — ข้อมูลที่ไม่อยู่ในส่วนที่จะถูก embed/retrieve ก็เหมือนไม่มี
3. **ระเบียบ ข้อ 6 ≠ retrieval signal สำหรับ "บอกเลิกสัญญา"** เพราะ ข้อ 6 ไม่มีคำนั้น — แม้จะ define อำนาจ "ดำเนินการตามระเบียบ" โดยรวมก็ตาม

## Deployment note

SCP → docker cp → force-reindex เสมอ ห้ามสลับลำดับ มิฉะนั้น embed จะทำงานกับไฟล์เก่าหลังจาก vectors ถูกลบไปแล้ว
