# ก่อนรายงานว่า "เสร็จแล้ว" ต้อง query ผลลัพธ์จริงเสมอ — ไม่ assume จาก exit code

ก่อนรายงานว่า "เสร็จแล้ว" ต้อง query ผลลัพธ์จริงเสมอ — ไม่ assume จาก exit code

- Spreadsheet: print headers ก่อน update, sample rows หลัง update
- Database: count rows ที่ยังผิดหลัง patch
- Derived fields: เมื่อ update ID ให้ update URL ที่ derived จาก ID ด้วยพร้อมกัน

เกิดขึ้นสองครั้งในวันเดียว (2026-04-14):
1. Patch Qdrant ด้วย xlsx โดยไม่ verify ว่า xlsx ถูกต้อง
2. Update Drive ID ใน xlsx แต่ไม่ update URL column เพราะไม่ดู schema ก่อน
