# ## ผู้มีอำนาจ ตาม ม.97, ม.102, ม.103 — Not the Same Person

## ผู้มีอำนาจ ตาม ม.97, ม.102, ม.103 — Not the Same Person

พ.ร.บ. uses "ผู้มีอำนาจ" in all 3 sections but ระเบียบฯ and กวจ rulings define it differently:

| มาตรา | เรื่อง | ผู้มีอำนาจ |
|---|---|---|
| 97 | แก้ไขสัญญา | ผู้มีอำนาจอนุมัติสั่งซื้อสั่งจ้าง (ตามวงเงิน) |
| 102 | งด/ลดค่าปรับ, ขยายเวลา | หัวหน้าหน่วยงานของรัฐ |
| 103 | บอกเลิกสัญญา | หัวหน้าหน่วยงานของรัฐ |

**ม.97** has 2 separate roles: (1) พิจารณาว่าสมควรแก้ไข + ลงนาม = หัวหน้าหน่วยงาน; (2) อนุมัติ = ผู้มีอำนาจอนุมัติสั่งซื้อสั่งจ้าง. ว476 key: "ไม่ว่ากรณีใด ย่อมต้องได้รับอนุมัติจากผู้มีอำนาจอนุมัติสั่งซื้อสั่งจ้าง"

**Wrong**: "ผู้มีอำนาจ" all 3 sections = หัวหน้าหน่วยงาน. Also wrong: all 3 = ผู้มีอำนาจอนุมัติสั่งซื้อสั่งจ้าง.

**Why ม.97 differs**: relates to money (เพิ่ม/ลดวงเงิน) → must go through procurement approval chain. ม.102+103 are contract administration, not money.
