# มาตรา 97 (แก้ไขสัญญา) vs มาตรา 102 (งดลดค่าปรับ): Scope vs Timing

## Pattern

ม.97 and ม.102 serve fundamentally different functions:

- **ม.97** = scope change → "งานเพิ่ม ต้องใช้เวลาเพิ่ม กี่วัน" → amend contract duration
- **ม.102** = timing issue → "งานเพิ่มจะเริ่มได้เมื่อไหร่ ถ้ารอ ใครรับผิดชอบ" → waive/reduce penalties

## Key Insight: Amendment Absorbs Delay

If ม.97 amendment sets a new future deadline → **no penalty exists yet** → no need for ม.102.

**Wrong**: "ครบกำหนดแล้ว + แก้ไขสัญญา = ต้องใช้ทั้ง ม.97 + ม.102"
**Right**: "แก้ไขสัญญาตั้งกำหนดใหม่ = สัญญายังไม่ครบ = ไม่มีค่าปรับ"

## When Both Are Needed

Only when the contractor exceeds even the AMENDED deadline, and the excess was caused by the state (e.g., state delayed providing conditions for the additional work to begin).

- ม.97: add 20 days for extra work (scope)
- ม.102: waive penalty for 30 days the state delayed providing work conditions (timing)
