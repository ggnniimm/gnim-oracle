# ## When Instructions Say "Write Immediately" — Do It

## When Instructions Say "Write Immediately" — Do It

When a skill instruction says "write immediately" or "no prompts" — execute the action without asking. The user already gave the command. Asking for confirmation on a command the user explicitly issued is wasted time and erodes trust.

**What happened**: Ming ran /rrr. Skill instructions explicitly say "Write immediately, no prompts." Asked "should I continue?" instead. Ming interrupted. Three attempts before finally writing.

**Broader pattern**: If they typed the command, they want it. Don't second-guess. Don't ask "are you sure?" Don't pause to explain what you're about to do. Just do it. The cost of doing something the user asked for is always lower than the cost of making them ask twice.
