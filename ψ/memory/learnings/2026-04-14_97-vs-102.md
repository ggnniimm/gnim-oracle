# ## มาตรา 97 (แก้ไขสัญญา) vs มาตรา 102 (งดลดค่าปรับ): Scope vs Timing

## มาตรา 97 (แก้ไขสัญญา) vs มาตรา 102 (งดลดค่าปรับ): Scope vs Timing

These serve fundamentally different functions:
- **ม.97** = scope change → amend contract (งานเพิ่ม → เวลาเพิ่ม)
- **ม.102** = timing issue → waive/reduce penalties when obstacle caused delay (งดลดค่าปรับ)

**Key insight**: If ม.97 amendment sets a new future deadline → no penalty exists yet → no need for ม.102.
- Wrong: "ครบกำหนดแล้ว + แก้ไขสัญญา = ต้องใช้ทั้ง ม.97 + ม.102"
- Right: "แก้ไขสัญญาตั้งกำหนดใหม่ = สัญญายังไม่ครบ = ไม่มีค่าปรับ"

**Both needed only when**: contractor exceeds even the AMENDED deadline, AND the excess was caused by the state.

**Historical mapping**: ระเบียบฯ 2535 ข้อ 136 = ม.97 (scope+time extension); ข้อ 139 = ม.102 (obstacle-based relief).
