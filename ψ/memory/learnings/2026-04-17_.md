# เอกสารกฎหมายไทย (ข้อหารือ/คำวินิจฉัย) มีโครงสร้าง: ข้อเท็จจริง → ประเด็นข้อหารือ

เอกสารกฎหมายไทย (ข้อหารือ/คำวินิจฉัย) มีโครงสร้าง: ข้อเท็จจริง → ประเด็นข้อหารือ (A หรือ B?) → ข้อวินิจฉัย → สรุปข้อวินิจฉัย

ถ้า chunk rank สูงสุดมาจากส่วน "ตั้งคำถาม" (ข้อเท็จจริง/ประเด็น) โดยไม่มีส่วน "ตอบ" LLM จะตอบผิดตามตัวเลือกแรกที่เห็น

Fix: เพิ่ม bullet ใน สรุปข้อวินิจฉัย ระบุคำตอบโดยตรง พร้อม negation ("ไม่ใช่ X") ใส่ต้น section เพื่อไม่ให้ CHUNK_SIZE=400 ตัด พบจาก amin chat session — query ผู้มีอำนาจงดหรือลดค่าปรับ ได้คำตอบผิด "ผู้มีอำนาจอนุมัติสั่งซื้อ" แทน "หัวหน้าหน่วยงานของรัฐ"
