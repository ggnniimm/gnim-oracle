# Standard Operating Procedure (SOP): High-Precision Thai Legal OCR Workflow

เอกสารฉบับนี้จัดทำขึ้นเพื่อเป็นมาตรฐานการถอดความเอกสารราชการและกฎหมายไทยที่มีความซับซ้อนสูง เพื่อให้ AI Agents สามารถทำงานร่วมกันได้อย่างมีประสิทธิภาพและรักษาความถูกต้อง 100%

---

## 1. การเตรียมข้อมูล (Pre-Processing)
- **Format:** แปลงไฟล์ PDF เป็นภาพ (PNG หรือ JPG) แยกรายหน้า
- **Resolution:** กำหนดความละเอียดขั้นต่ำ **300 DPI** เพื่อให้เห็นรายละเอียดหัวสระและวรรณยุกต์ไทย
- **Colorspace:** ใช้ RGB เพื่อคงรายละเอียดของตราประทับสีหรือรอยปากกา

## 2. กลยุทธ์การสั่งงาน (Expert Prompt Strategy)
ใช้ Prompt ที่ระบุบทบาทและกฎเกณฑ์ที่เข้มงวด เพื่อป้องกัน AI สรุปความหรือแก้ไขเนื้อหา:

### 2.1 Role Identity
กำหนดบทบาทเป็น **"หุ่นยนต์ OCR ระดับสูง (High-Precision OCR Expert)"** ที่มีความเชี่ยวชาญด้านเอกสารราชการไทย

### 2.2 กฎเหล็ก (Core Constraints)
1. **100% Verbatim:** ถอดข้อความคำต่อคำ ห้ามสรุป ห้ามข้าม และห้ามแก้คำผิด (แม้ต้นฉบับจะพิมพ์ผิด)
2. **Script Integrity:** รักษา "เลขไทย" ให้เป็นเลขไทยตามที่ปรากฏ ห้ามแปลงเป็นเลขอารบิก
3. **No Interpretations:** ห้ามเพิ่มคำเกริ่นนำหรือคำอธิบายประกอบ
4. **Anchor Validation:** ระบุเลขหน้าที่ AI กำลังประมวลผล เพื่อให้ AI ใช้เป็นจุดยึดตรวจสอบความถูกต้องของตำแหน่ง

## 3. การตรวจสอบตัวเอง (Reflexive Verification)
รวม "คู่เทียบที่สับสนบ่อย (Confusion Matrix)" ไว้ใน Prompt เพื่อให้ AI ระมัดระวังเป็นพิเศษ:
- **'๒' (สอง)** vs **'๖' (หก)**
- **'๔' (สี่)** vs **'๕' (ห้า)** vs **'๙' (เก้า)**
- **'๘' (แปด)** vs **'๓' (สาม)**

## 4. การจัดการระบบ (Execution & Rate-Limit)
- **Sequential Task:** ประมวลผลทีละหน้า เพื่อป้องกันปัญหา Context Overflow
- **Rate-Limit Handling:**
    - เว้นระยะห่าง (Sleep) อย่างน้อย 10-20 วินาทีระหว่างหน้า
    - ใช้ระบบ **Exponential Backoff** (หยุดรอและเพิ่มเวลา 2 เท่า) เมื่อเจอ Error 429 (Rate Limit Exhausted)
- **Verification Loop:** หากพบความไม่แน่ใจในบางจุด ให้ AI ทำการ Re-scan เฉพาะจุดนั้นด้วยระดับ "Thinking: High"

## 5. การจัดโครงสร้างผลลัพธ์ (Post-Processing)
- **Format:** บันทึกเป็นไฟล์ Markdown (.md)
- **Metadata:** กำกับหมายเลขหน้าด้วยคอมเมนต์ HTML เช่น `<!-- Page X -->` เพื่อให้ง่ายต่อการนำไปใช้ใน RAG
- **Auto-Naming:** ใช้ AI วิเคราะห์ 3 หน้าแรกของเนื้อหาเพื่อตั้งชื่อไฟล์ตามรูปแบบ:
    `[ชื่อหน่วยงาน]_[ประเภทเอกสาร]_[เลขที่]_[ปี].pdf`

## ตัวอย่าง Expert Prompt Template
```markdown
คุณคือหุ่นยนต์ OCR ระดับสูง ถอดข้อความจากภาพนี้แบบ 100% Verbatim

══ ข้อมูลหน้านี้ ══
นี่คือหน้าที่ {page_num} จากทั้งหมด {total_pages} หน้า

══ กฎเหล็ก ══
1. ห้ามสรุป ห้ามข้าม ห้ามแก้คำผิด แม้ต้นฉบับจะพิมพ์ผิด
2. รักษาเลขไทยตามต้นฉบับ ห้ามอ่านสลับเป็นเลขอารบิก
3. ถอดข้อความแบบคำต่อคำ ห้ามมีคำเกริ่นนำใดๆ
4. รักษาโครงสร้างย่อหน้าและลำดับข้อความให้ตรงตามภาพ
```
